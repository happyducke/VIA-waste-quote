# VIA Waste Quote Demo

VIA Mobile360 / vCare sales quoting demonstration.

The supplied single-file application is preserved unchanged, including its encrypted sign-in gate. Use the existing demo credentials. HTTPS is required for browser Web Crypto.

Demo prices are for evaluation only. Do not use real customer information in demonstrations.

## Hosting

Published with GitHub Pages from the root of the `main` branch. Updates to `index.html` on `main` are deployed automatically.

## Admin access

The Admin view requires a separate credential to decrypt its interface. Admin access is cleared when switching to Dealer or Sales and is never restored from a saved role. Passwords are not stored in this repository. This is a browser-only demo; shared production pricing and permissions require server-side authorization.
